# Controller-image edit prompts

The final images were edited with the built-in `image_gen` tool from the existing guides based on [Meta's official Quest 3 Touch Plus artwork](meta/quest-3-touch-plus.png). See [source and usage terms](README.md).

Current requirements: no full-width footer text, no world-drag default-state badge, and no instruction to enable world drag before using the new defaults.

## en

```text
Use case: precise-object-edit. Image 1 is the existing SCSP VR controller-guide edit target, based on official Meta Quest 3 Touch Plus line-art. Make ONLY these changes: 1. Completely remove the two full-width footer sentences and their enclosing gray/black/outlined bands below the controller drawings, restoring plain white background. 2. In the RIGHT Grip / World Drag callout, DELETE the colored default-OFF badge altogether; do NOT replace it with any ON, OFF, automatic, enabled, or default-status wording. Replace its enable-in-settings instruction with the exact short hand-motion instruction supplied below. Keep this callout neat with just its heading and hand-motion instruction. World drag now works by holding right Grip; no setup instruction is needed here. Preserve every other word, title, hand label, joystick/face buttons, six control mappings, all original official line-art geometry, button positions, existing single A leader, other leader lines, typography, palette and canvas dimensions. Do not add a trigger leader. Do not add new footer text or default-state badges. Leave bottom as plain white. World-drag box should contain ONLY heading 'GRIP — WORLD DRAG' and instruction 'Hold right Grip and move your hand'. Other English callouts unchanged.
```

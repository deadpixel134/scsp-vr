# Controller guide artwork

The SCSP VR controller guides use Meta's official **Quest 3 Touch Plus** controller drawings from **Meta Quest Hardware Art 1.8**, with localized SCSP VR control annotations added using the built-in `image_gen` tool.

- [Official artwork download page](https://developers.meta.com/vr/downloads/package/oculus-controller-art/)
- Package file: `oculus-controller-art-v1.8.zip`, original image: `Meta Quest Touch Plus/Quest_03.png`
- [Unmodified reference image](meta/quest-3-touch-plus.png)

All versions show the same defaults: left stick turns/tilts, left Grip toggles the 3D hand panel, right stick moves, A/right trigger clicks and drags, B sends Back while pointing at a panel, and holding right Grip while moving the right hand performs world drag. The images intentionally omit default-state badges and footer sentences. Keep the README control tables alongside the images for accessible text and full details.

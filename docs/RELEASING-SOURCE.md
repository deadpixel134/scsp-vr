# Corresponding source for SCSP VR releases

Publish the binary ZIP alongside the complete corresponding source, including
the source and scripts needed to build and install it. Link directly to the
matching source from the release page. Before publishing, check that the tag
in SOURCE-CODE.txt identifies the commit used to build the binary and that its
archive contains the complete corresponding source.

For code derived from SCSP-localify, record the upstream revision and affected
files, preserve the upstream notices, and describe changes to copied files.
The exact revision for the integration identified in CREDITS.md remains
unverified.

The distribution ZIP includes the source for its separately bundled Unity
Doorstop 4.5.0 binary.
